FREQUENTLY ASKED QUESTIONS

Everything You Need To Know About FileGuard

Answers to common questions regarding security, retention policies, and file sizes.

How long are shared files stored on FileGuard? +
Every uploaded file or folder bundle remains active for exactly 12 hours from the upload timestamp. Once 12 hours elapse, FileGuard's automated sweeper purges the file from Backblaze B2 cloud storage and marks the record expired.
Do I or the recipient need to create an account? +
No. FileGuard requires zero accounts, email addresses, or passwords. Uploaders and recipients enjoy total anonymity. You can track your activity directly in the client-side 'My History' vault on your browser.
Can I upload an entire folder without compressing it first? +
Yes! You can drag and drop an entire folder hierarchy or select multiple files. FileGuard streams them into an in-memory ZIP bundle with full directory structure preservation, saving you the hassle of manually creating a ZIP archive.
How does the pre-flight SHA-256 anti-tamper check work? +
When an upload is received, FileGuard computes its immutable SHA-256 hash. On every download request, the server re-computes the hash of the storage block before sending it to the client. If any bit has changed due to tampering or storage degradation, the transfer is blocked with HTTP 409 Anti-Tamper Protected.
What is the maximum file size limit and upload quota? +
You can upload single files or folder bundles up to 100 MB per transfer. Each client IP has a rolling quota of 100 MB per 12 hours, ensuring the platform remains free, fast, and protected against automated spam and resource exhaustion.
Can I revoke or delete my file before 12 hours? +
Yes. Visit the 'My History' page from the browser used to upload the file, and click 'Revoke & Purge'. This immediately purges the file from cloud storage and invalidates the link for all recipients.
